Getting Started
  🚀 Command-Line Mode (CMD)

  Download Rezolv.exe from this repository.

  Run it directly by double click.

Simple. Efficient. No ceremony.

🖥️ GUI Mode

Install Node.js (npm) on your system.

Download Rezolv GUI.zip from the repository (use the raw download option).

Extract the ZIP file.

Run GUI.cmd to launch the GUI interface.

And just like that — visuals unlocked.
